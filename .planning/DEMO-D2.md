# Демо D2 — сравнение с референсом

Демо D2 — главная точка сравнения. Скриншот кладётся рядом с кадром референса,
и решается: добираем картинку или идём в музыку.

## Коды сида по настроениям

| Настроение | Сид | Кадр референса |
|---|---|---|
| serene | 0000-5hgu-kr2i | Тихий мир с бирюзовыми глифами, мягкое свечение |
| eerie | 0000-5hgu-kr4a | Тёмно-красный мир, плотный туман, жуткая атмосфера |
| void | 0000-5hgu-kr62 | Почти чёрный мир, серые глифы, ощущение пустоты |
| joyful | 0000-5hgu-kr7u | Яркий мир, жёлто-розовые глифы, быстрая пульсация |
| uncanny | 0000-5hgu-kr9m | Смешанный мир, зелёно-голубые глифы, неестественная светимость |
| claustrophobic | 0000-5hgu-krbe | Тесный мир, тёмно-серые глифы, густой туман |

## Что собрано в D2

- Композер с bloom и дисторсиями (fisheye, chroma)
- Отражающий пол (`buildFloor`): плоскость пола уходит вдвое дальше дальней
  границы мира по −Z, в кадр от точки входа попадает её передняя полоса;
  отражения ближнего к линии пола слоя усилены, чтобы «мокрый пол» читался
  с уровня глаз
- Надписи из глифов (`buildFormulaPlane`)
- Палитры настроений
- Формовое поле
- Невозможные фигуры
- Портал выхода

## Экспорт post

`post` экспортирован из `boot.js`:
```js
export const post = buildComposer(renderer, scene, camera);
```

Проверка в консоли:
```js
import("/src/boot.js").then(m => [typeof m.post, typeof m.post.setFisheye])
// ["object", "function"]
```
