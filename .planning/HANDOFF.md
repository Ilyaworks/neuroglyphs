## Дыра закрыта (2026-08-21)

Заказчик хотел композицию «сфера в середине, вокруг кольцо, между ними пусто».
Причина, почему её не было: (1) вырожденный хеш `h(n)` слипал точки, (2) в наборе
не было форм с явным провалом. Оба пункта закрыты: хеш заменён на splitmix32,
добавлены 6 форм-«светил» и 4 формы с пустой серединой (см. таблицу выше).

Текущий замер провала (колонка «провал» в `node tools/shape-check.mjs`):

## Причина низкой заполненности форм — устранена (2026-08-21)

Хеш `h(n)` в `shapePatch.js` был **вырожден**: соседние аргументы давали связанные
значения (корреляция -0.4184, заполненность чистого хеша 0.085 против 0.771 у splitmix32
и 0.767 у Math.random). Из-за этого точки слипались, и все формы, построенные на `h(i)`,
получали низкий объём — отсюда и «везде скопление», и провал у первых «звёздных» форм.

Хеш заменён на splitmix32, геометрия всех форм на `h(i)` изменилась, списки и галерея
пересобраны (`node tools/pick-dense-shapes.mjs`, `node tools/gen-seeds-gallery.mjs`,
`node tools/shape-check.mjs`). Текущий x в `shapePatch.js`:

```js
export function h(n) {
  let x = (n + 0x9e3779b9) >>> 0;
  x ^= x >>> 16; x = Math.imul(x, 0x21f0aaad) >>> 0;
  x ^= x >>> 15; x = Math.imul(x, 0x735a2d97) >>> 0;
  x ^= x >>> 15;
  return (x >>> 0) / 4294967296;
}
```

## Особенность OpenChamber, из-за которой терялось время

Приложение читает `~/.config/opencode/opencode.json` **при запуске**. Если поменять
`baseURL` (например, переключить на прослойку) при открытом приложении, работающие сессии
продолжат ходить по старому адресу — и модель снова уйдёт в размышления на десятки тысяч
символов. После правки конфига OpenChamber надо закрыть полностью и открыть заново.

## Как устроены формы (важно для правок)

- `src/world/legacyShapes.js` — 169 старых форм, перенесены из `main.js`. Используют общий
  сеяный генератор, `main.js` подставляет его через `setRng()`.
- `src/world/shapeCatalog.js` — 40 новых форм; `shapePatch.js` подменяет одноимённые и
  добавляет новые (механизм сделан специально, чтобы **не править большой файл**).
- `src/world/allShapes.js` — объединение: при совпадении имён побеждает каталог.
- `src/world/fieldShapes.js` — **генерируется**, руками не править:
  `node tools/pick-dense-shapes.mjs`, затем `node tools/gen-seeds-gallery.mjs`.
- Контракт формы: `(i, p, out)` пишет `out[0..2]`; никакого `Math.random()`; параметры
  только из 16 полей `p` (radius, flatten, distPow, tubeR, arms, twist, spread, thickness,
  strands, turns, clusterCount, clusterRadius, freq, amp, knotP, knotQ).

## Ограничения окружения

- Локальная модель (Qwen3.8-27B через OpenChamber/opencode) **надёжно создаёт новые файлы
  и не умеет править большие**. Всё, что касается `main.js`, делает Claude.
- Прослойка `C:\Users\onlin\cline-llm-proxy\start-proxy.cmd` должна быть запущена: без неё
  модель уходит в размышления и молча обрывает ход по лимиту вывода.
- Промты для модели — по-русски, приказом, с одной командой проверки и явным STOP.
