# ISSUES — NEUROGLYPHS (Concept v2)

Задачи под GitHub: `https://github.com/Ilyaworks/neuroglyphs`.
Полный дизайн: `.planning/CONCEPT.md`. Референс картинки: 13 кадров, цель — воспроизвести их.

**Правило дробления:** одна задача = один issue = одна сессия = один новый файл размером
до 150 строк. Если задача не влезает в один файл — она разбита на подзадачи с буквами
(`N12a`, `N12b`). Сессия может сжиматься по контексту, поэтому в задаче всегда указан
точный список файлов для чтения — читать что-то ещё запрещено.

## Правила для исполнителя (вставлять в каждую сессию)

1. Не составляй план. Первым действием создавай файл.
2. Один новый файл за сессию. Правки существующих файлов разрешены только там, где задача
   прямо говорит, какой файл и сколько строк.
3. Читай только перечисленные файлы. Ничего больше не открывать.
4. Никакого `Math.random()` в генерации — только сеяный PRNG из `src/core/rng.js`.
5. Все визуалы — глифы, точки, линии, шейдеры на глиф-геометрии. Других ассетов нет.
6. Никакого текста как интерфейса внутри мира: задачи сообщаются цветом, пульсацией,
   частотой. Формулы и надписи — декор.
7. Тот же сид = тот же мир побайтово. Задача, добавляющая параметр, добавляет и проверку.
8. Пороги в инструментах проверки менять запрещено. Не проходит — значит не готово.
9. В конце — одна команда проверки из задачи и явный STOP с отчётом.

# Дорожная карта

Шесть демо-точек. В каждой есть что показать на экране; между ними ничего не «висит
недоделанным».

| Демо | Что видно | Задачи | Штук | Сессий |
|---|---|---|---|---|
| **D1 — Первый мир** | Летаешь по миру из глифов, восемь типов структур, туман, светящийся портал выхода | N01–N21 | 21 | 24–28 |
| **D2 — Картинка как на референсе** | Свечение, дисторсии, зеркальный пол, палитры настроений, 64 формы, формулы | N22–N31 | 10 | 12–14 |
| **D3 — Музыка = сердцебиение** | Мир пульсирует под твой трек, BPM и тональность, дрон по умолчанию | N32–N40 | 9 | 10–12 |
| **D4 — Сбор и прогресс** | 128 вещей в мире, счётчик `042 / 128`, близость выхода, собранное меняет сид | N41–N46 | 6 | 7–9 |
| **D5 — Бесконечность** | Переход между мирами, курированные сиды, меню, world book, шаринг кода | N47–N52 | 6 | 7–9 |
| **D6 — Атмосфера и полировка** | Дыхание, созвездия, эхо, моире, задачи без текста, настройки качества | N53–N62 | 10 | 11–13 |

Итого 62 задачи, порядка 75 сессий модели с учётом повторных попыток. Одна проверка с моей
стороны на задачу.

**Когда демо актуально показывать:**

- **D1** — первая точка, где проект перестаёт быть заготовкой: есть мир, есть полёт, есть
  выход. Показывать, чтобы решить, та ли это геометрия.
- **D2** — точка сравнения с референсом. Здесь кладём скриншот рядом с кадром и решаем,
  добираем ли ещё картинку или идём дальше. Это самая важная демо-точка проекта.
- **D3** — точка, где становится понятно ядро идеи: без музыки калейдоскоп мёртвый.
- **D4** — первая точка с геймплеем: сбор и прогресс.
- **D5** — точка, где игра становится бесконечной, а не одним миром.
- **D6** — то, что делает миры разными по ощущению, а не по геометрии.

Критический путь до первой картинки: `N01 → N02 → N03 → N05 → N06 → N07 → N09 → N10 → N11`
— девять задач, после них на экране уже светящееся глифовое поле по коду сида.

Дальше до D2 добираются `N12 → N13 → N14 → N16` (структуры), `N22 → N25 → N26` (свечение
и палитры), `N27 → N28` (формы), `N29` (пол). Тесты (`N04`, `N08`, `N15`) можно двигать, но
не откладывать за пределы своей демо-точки: без них детерминизм перестаёт проверяться.

Идут параллельно и не блокируют картинку: движение (`N19`, `N20`), музыка (`N32`–`N37`),
формулы (`N30`).

## N03 — Сеяный PRNG

**Файлы:** создать `src/core/rng.js`
**Читать:** —
**Метки:** `area:core`, `epic:D1`

- `mulberry32(seedInt)` → функция без аргументов, `[0, 1)`.
- `strToSeed(str)` → 32-битное целое из строки (FNV-1a).
- `hash32(n)` → `[0, 1)`, реализация строго splitmix32:
  ```js
  let x = (n + 0x9e3779b9) >>> 0;
  x ^= x >>> 16; x = Math.imul(x, 0x21f0aaad) >>> 0;
  x ^= x >>> 15; x = Math.imul(x, 0x735a2d97) >>> 0;
  x ^= x >>> 15;
  return (x >>> 0) / 4294967296;
  ```

Хеш на одном сдвиге брать нельзя: замером получено, что он даёт корреляцию соседних
значений −0.42 и заполненность объёма 0.085 против 0.77 у splitmix32 — точки слипаются
в комок, и все формы выходят вырожденными.

**Проверка:** `node -e "import('./src/core/rng.js').then(m=>console.log(m.hash32(1).toFixed(4)))"`
— печатает число между 0 и 1.

## N61 — Neuro-prompt: схема и валидатор

**Файлы:** создать `src/neuro/tweaks.js`
**Читать:** `src/core/seed.js`, `src/art/palettes.js`
**Метки:** `area:core`, `epic:D6`

Схема JSON допустимых твиков (сдвиг палитры, морф структуры, плотность, настроение,

системы и не создаёт новых объектов.

**Проверка:** `node -e "import('./src/neuro/tweaks.js').then(m=>console.log(typeof m.applyTweaks))"`

## Открытые вопросы, которые закрываются решением, а не кодом

1. Мягкий предел на количество носимых вещей: сколько, прежде чем сид переполнится.
2. Неевклидовы комнаты: как сделать дверь в ту же комнату, не сломав навигацию.
3. Кто отбирает сто курированных сидов: алгоритмический счёт из `N50` или ручной просмотр.
4. Мобильные устройства: подтверждено ли, что приоритет низкий.
