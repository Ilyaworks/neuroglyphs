# Промт для сессии модели

Вставлять в начало новой сессии Квена целиком, ниже разделителя. Текст постоянный —
он не зависит от задачи, задачу выдаёт `next-task` уже внутри сессии.

Схема работы: вы сидите в одной сессии, модель делает задачи подряд и сама берёт
следующую. Останавливается и спрашивает вас только в двух случаях: нужна приёмка
глазами (вы смотрите картинку и говорите «принято» или «не принято, потому что…»)
и провал после трёх попыток. Новая сессия нужна, когда модель сама её попросит —
после трёх закрытых задач контекст распухает и качество падает.

Если не помните, чей ход: `node tools/what-now.mjs`

---

Первым действием выполни: node tools/next-task.mjs

Дальше делай ровно то, что он напечатал, и ничего сверх этого.

## Правила, которые важнее любой задачи

1. Правь только файлы из списка задачи. Каталог tools/ не трогать никогда — если
   гейт кажется неправым, прогони его дважды на одном и том же выводе и напечатай
   ПРОВАЛ с числами, но инструмент не правь.
2. Не запускать git reset --hard, git checkout -- . и git stash. Ими уже трижды
   стёрло чужую незакоммиченную работу. Отменять только по именам файлов:
   git checkout HEAD -- <файл>.
3. Не править .planning/ISSUES.md и .planning/BACKLOG.md руками, не менять пороги
   в тестах и инструментах.
4. Отчёт не сочинять. Числа брать из вывода команд, а не по памяти.

## Как закрывать задачу

1. Выполни команду проверки из задачи. Не прошла — исправь и запусти снова, но не
   больше трёх попыток. После трёх — напечатай «ПРОВАЛ <номер>», приложи точный текст
   ошибки и остановись.
2. Прошла — выполни: node tools/finish-task.mjs <номер>

Дальше одно из двух.

**Задача закрылась.** Сразу выполни node tools/next-task.mjs и начинай следующую,
человека не спрашивай. Так подряд, пока не закроешь три задачи — после третьей
напечатай «нужна новая сессия, контекст распух» и остановись.

**finish-task отказал словами «нет вердикта приёмки глазами».** Это НЕ поломка и не
повод запускать снова. У задачи приёмка назначена глазами, и решает человек:

  1. пересними картинку (команда указана в задаче, обычно node tools/forms-sheet.mjs);
  2. напечатай человеку блок «ЧТО ПРОВЕРИТЬ ГЛАЗАМИ» ЦЕЛИКОМ, как его выдал
     инструмент, ничего не сокращая и не пересказывая;
  3. спроси: «принято или не принято?» и ЖДИ ответа. Не работай дальше, не бери
     другую задачу, не выноси вердикт сам.

Когда человек ответит:

- сказал «принято» (или «да, принято», «всё верно») — выполни
  node tools/verdict.mjs <номер> да --via-model
  затем node tools/finish-task.mjs <номер> — теперь пройдёт;
- сказал «не принято» и назвал причину — выполни
  node tools/verdict.mjs <номер> нет "его причина своими словами" --via-model
  и правь ровно то, что он назвал. Спорить с ним замерами нельзя: гейт мерит то,
  что умеет измерить, а решает картинка.

Вердиктом считается только прямой ответ про эту картинку. «Ок», «продолжай»,
«хорошо», «давай дальше» и молчание вердиктом НЕ являются — если ответ непонятен,
спроси ещё раз и жди. Зелёные гейты вердиктом тоже не являются: именно так закрылась
R25 при семи одинаковых формах на листе.
