Файл должен экспортировать ровно это:

```js
export function h(n) {            // оставить как есть
  let x = (n ^ 0x9e3779b9) >>> 0;
  x = Math.imul(x ^ (x >>> 15), 0x85ebca6b) >>> 0;
  return ((x ^ (x >>> 13)) >>> 0) / 4294967296;
}

export const PATCH = {
```

## Что должно быть в PATCH

**Девять переделанных форм — имена в точности такие:**

```
tetraWire      сейчас заполненность 0.036, нужно >= 0.12
cubeLattice    0.042
colonnadeRing  0.026
octaFrame      0.090
ziggurat       0.093
icoLattice     0.108
domeShell      радиальный пик 0.864, нужно <= 0.45
archBridge     пик 0.460
logSpiral      пик 0.517
```

Идею каждой формы сохранить, но набрать объём:

- у первых шести проблема «проволочный каркас»: точки сидят точно на рёбрах или линии.
  Разбрасывай их вокруг ребра на величину до 15% от `p.radius` через `h(i)` и часть точек
  уводи внутрь объёма, а не только на рёбра;
- у `domeShell`, `archBridge`, `logSpiral` проблема «одна тонкая оболочка»: все точки на
  одном радиусе. Раздай их по нескольким вложенным слоям разной плотности, от центра до края.

**Четыре новые формы — семейство «ядро + кольцо».** В середине плотное светило с лучами,
вокруг него отдельное кольцо, между ними явный провал плотности. Вдохновение — звёзды:
протуберанцы и лучи короны, аккреционный диск, кольца Сатурна с щелью, шаровое скопление
с уплотнением к центру. Требования к каждой:

- доля точек ближе 0.25 максимального радиуса — не меньше 0.15;
- доля точек дальше 0.60 максимального радиуса — не меньше 0.25;
- заполненность — не меньше 0.15;
- у ядра направленные сгущения (лучи), а не ровный шар.

Имена новым формам придумай сам, латиницей, в стиле существующих.

## Требования к коду

- Чистые функции `(i, p, out)`: только запись в `out`, никакого состояния между вызовами.
- Никакого `Math.random()`, никаких импортов. Только `Math` и `h(n)` из этого файла.
- Никаких NaN и Infinity ни при каком `i` от 0 до 6000.
- Из параметров только эти поля `p`: `radius, flatten, distPow, tubeR, arms, twist, spread,
  thickness, strands, turns, clusterCount, clusterRadius, freq, amp, knotP, knotQ`.
- Каждой форме — строка комментария на русском: что видно глазом.
- Никакие другие файлы не менять: ни `shapeCatalog.js`, ни `main.js`, ни `tools/`.

## Проверка

Запусти:

```
node tools/shape-check.mjs
```

Успех — это строка `не проходят проверку : 0` и четыре твоих новых имени в строке
`семейство ядро+кольцо`. Пороги в инструменте не менять, проверку не ослаблять, формы из
`PATCH` не удалять ради зелёного результата. Если после трёх попыток одна конкретная форма
не проходит — оставь остальные рабочими, скажи, какая не идёт, и остановись.

Когда проверка зелёная — покажи её вывод и остановись.
